# NEON DASH

A fast-paced rhythm-action neon gauntlet for desktop and mobile browsers.

## Features

- **STEREO PULSE:** Hand-crafted 60-second stage with beat-synced visuals, jump pads, boost rings, and color shifts.
- **Cube & Ship Modes:** Portals switch mid-run between snappy cube platforming and jetpack flight.
- **Endless & Practice Modes:** Procedural endless mode with escalating speed, plus auto-checkpoint practice mode.
- **Cube Skins:** Selectable neon cube designs saved locally in your browser.
- **Instant Respawn:** Quick 0.35s respawn after crashes with zero pop-up delays.

## Controls

| Platform | Input | Action |
| :--- | :--- | :--- |
| **Desktop** | `Space` · `W` · `↑` · `Left Click` | Jump / Fly *(hold for continuous jumps)* |
| **Shortcuts** | `R` · `P` · `M` | Restart · Pause · Mute |
| **Mobile** | `Tap` / `Hold` | Jump / Fly *(landscape recommended)* |
