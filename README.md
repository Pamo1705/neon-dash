## 🎮 Controls

| Platform | Input | Action |
| :--- | :--- | :--- |

| **Quick Keys** | `R` · `P` · `M` | Instant Restart · Pause · Mute / Unmute |
| **Mobile & Tablet** | `Tap` / `Hold` anywhere | Jump / Fly *(landscape recommended)* |
